背景說明:為什麼要看這些

CRS 只看徵象,為什麼會演變成 HLH 樣症候群?

重點
兩者是同一條發炎路徑的不同方向。徵象分級只量血壓與氧氣,看不到後者。
機制
  1. CAR-T 活化,釋出 IFN-γ、GM-CSF
  2. 巨噬細胞被帶動,產生 IL-6、IL-1:發燒、血管滲漏、低血壓(一般的 CRS)
  3. 巨噬細胞持續被 IFN-γ 驅動而停不下來:吞噬血球、ferritin 暴升、纖維蛋白原被消耗、肝功能異常、血球低下
床邊看什麼
  • 退燒後又燒起來
  • ferritin 快速上升
  • 纖維蛋白原下降
  • 轉胺酶上升
  • 血球回升後又掉下去
怎麼做
有新報告就填第三步。懷疑時先照 CRS 處置。
依據
SITC 2020:兩者大幅重疊;晚發且 tocilizumab 無效者可能是不同病理(證據等級 4)。巨噬細胞放大的證據主要來自動物模型。

發生之前,臨床上會很嚴重嗎?

重點
不一定。先前的 CRS 可以很輕。
時間點
  • 常在 CRS 緩解中或緩解後出現
  • 也有治療後一度改善又惡化的
  • 多數先有 CRS,但不是一定
床邊看什麼
可能很平靜:血壓穩、不需氧氣、CRS 0 或 1 級。變化在檢驗值。
怎麼做
CRS 降級不能當成安心訊號,要同時看 ferritin 與纖維蛋白原的方向。
依據
ASTCT 2023 IEC-HS 共識的定義與註腳。

CRS 級數慢慢升,ferritin 卻飆得很快?

重點
巨噬細胞活化的程度,超過目前血壓與氧氣所反映的。
可能走向
  • CRS 即將跟上,一兩天內升級
  • 走向 HLH 樣症候群
  • 自行回落,臨床安好
怎麼分辨
不是看 ferritin 還會多高,而是看纖維蛋白原、轉胺酶、血球有沒有在 72 小時內一起變化。
怎麼做
不必因此升級 CRS 處置;把纖維蛋白原、凝血、肝功能、血球改為每日追蹤,並先排查感染。
依據
ASTCT 2023:有病人檢驗明顯異常但臨床安好;分級依臨床後果而非 ferritin 高低。三種走向的比例、上升速度與預後的定量關係,沒有找到可引用的數字。

血壓正常,為什麼會寡尿?

重點
寡尿是代償還在運作的訊號,常比低血壓早出現。
機制
  1. 血管擴張與微血管滲漏,有效循環血量下降
  2. 交感神經、腎素系統、抗利尿激素啟動,把血壓撐住
  3. 代價是腎臟留鈉留水,尿量減少
其他原因
  • 心輸出量下降
  • 急性腎小管損傷
  • 腫瘤溶解
  • 腎毒性藥物、顯影劑
  • 大量輸液後腹內壓上升
  • 尿滯留或導尿管阻塞
床邊看什麼
  • 心跳是否變快、脈壓是否變窄
  • 體重與輸出入量
  • 肌酸酐趨勢、乳酸
  • 周邊是冷的還是暖的
怎麼做
通報。原因不同處置相反:滲漏與心功能差的病人多給水反而肺水腫,寡尿不等於多給水。
依據
一般生理知識,未對照特定文獻。ASTCT 規定器官毒性不影響 CRS 分級;SITC 把肌酸酐上升列為需通知醫師的變化。

ferritin 為什麼會升高?

重點
血中的 ferritin 主要來自巨噬細胞與肝細胞,反映這兩類細胞被活化或受損,不是鐵變多。
四條路
  1. 發炎細胞激素誘導合成(急性期反應)
  2. IL-6 經 hepcidin 把鐵扣在巨噬細胞內
  3. 被 IFN-γ 強力活化的巨噬細胞吞噬血球後主動分泌:能衝到上萬的主因
  4. 肝細胞等受損後釋出
判讀注意
  • 輸血、肝病、腫瘤本身會讓基線偏高,要有輸注前的基線
  • 感染也會升高,不具特異性
  • 升得快、降得慢,要看方向
  • 給過 tocilizumab 後 CRP 被壓低,不代表發炎已停;這時 ferritin 較可靠
依據
一般免疫與生理知識,未對照特定文獻。

為什麼不能先排除感染再處置?

重點
以小時計的時間內排除不了感染,所以感染評估與 CRS 處置並行。
怎麼做
  1. 第一次發燒就抽血液培養,依本院準則給經驗性抗生素
  2. 同時照分級處置,不等培養
  3. 滿 48 小時陰性且臨床穩定,再考慮降階
  4. 每次新發燒、惡化或加重免疫抑制,重抽並擴大檢查
陷阱
tocilizumab 與類固醇會壓住發燒與 CRP。用藥後即使不發燒,惡化時也要抽培養。
時序
輸注後 28 天內以細菌感染為主,之後病毒較多;注意 CMV、EBV、HHV-6 再活化。
依據
ASTCT 2023、SITC 2020。各項檢查的回報時間與 procalcitonin 鑑別力有限,是一般知識。

二、分級規則摘要

  • CRS:需有 38°C 以上且非其他原因的發燒;級數取低血壓與缺氧較重者。已因 CRS 用過退燒藥、tocilizumab 或類固醇者,之後分級不再需要發燒。器官毒性不影響分級。
  • ICANS:取 ICE、意識、癲癇、運動、顱內壓五項中最重者。ICE 0 分而清醒且全面失語為 3 級,無法喚醒為 4 級。顫抖與肌躍症不影響分級;顱內出血不列入。
  • IEC-HS:ferritin 為必要條件;須排除 CRS、感染與疾病惡化;分級依臨床後果。
